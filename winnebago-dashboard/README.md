# 🚐 Winnebago Connect Dashboard Project

## Overview

This project focused on transforming connected RV telemetry data into actionable business insights through interactive Power BI dashboards.

Working with Winnebago Connect™ data, our team analyzed customer camping behavior, travel activity, power consumption, alerts, and feature engagement to better understand how customers interact with their motorhomes.

The project emphasized turning large, complex datasets into intuitive visualizations that support business decision-making and customer experience improvements.

---

# Business Objective

The goal of this project was to help Winnebago better understand customer usage patterns and identify opportunities to improve connected coach features, customer satisfaction, and future product development.

### Key Business Questions
- How are customers using their RVs?
- What behaviors indicate camping vs. boondocking activity?
- Which features are underutilized?
- How can telemetry insights improve customer experience and product strategy?

---

# Dashboard Features

## 📍 Camping & Boondocking Analysis
- Classified camping behavior using power thresholds, lighting activity, and shore power usage
- Identified off-grid boondocking trends
- Tracked occupancy and usage patterns

---

## ⚡ Power Usage Monitoring
- Combined shore, solar, generator, and alternator power into unified reporting measures
- Visualized energy consumption trends
- Compared power usage across camping types

---

## 🚗 Travel Insights
- Used GPS telemetry data to identify travel activity
- Tracked customer travel behavior and movement patterns
- Built daily travel summaries using VIN and Date relationships

---

## 🚨 Alerts & Commands
- Analyzed alert frequency and customer command activity
- Evaluated feature engagement and system interactions
- Identified opportunities for proactive support and maintenance

---

# Technical Contributions

- Built and tested DAX measures for camping classification logic
- Integrated telemetry, geo, alerts, and command datasets using VIN and Date relationships
- Developed interactive dashboard pages in Power BI
- Created calculated columns and business logic measures
- Supported data validation and dashboard testing
- Helped translate technical data into clear stakeholder insights
